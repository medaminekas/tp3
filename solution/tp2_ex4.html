Le Web et le Langage HTML

Une courte introduction aux fondamentaux du Web moderne.

I. Qu'est-ce que le Web ?

Le World Wide Web est un système hypertexte public fonctionnant sur Internet.
Il permet de consulter des pages de contenus à l'aide d'un navigateur.

Les trois piliers du Web

  1. Les adresses URL (pour localiser une ressource)
  2. Le protocole HTTP (pour transférer les données)
  3. Le langage HTML (pour structurer le contenu)

II. Le Langage HTML

HTML signifie HyperText Markup Language. Ce n'est pas un langage de programmation, mais un langage de balisage.

II.1. Technologies associées

  • CSS (pour la mise en forme)
  • JavaScript (pour l'interactivité)

II.2. Lexique de base

Balise
Élément de code permettant de structurer le texte (ex: <p>, <h1>).
Lien hypertexte
Élément permettant de naviguer d'une page à une autre.
